SGV & Inland Empire Chamber Events

A combined events calendar harvested nightly from local chamber of commerce and business association websites.

Feed URL (subscribe once, updates automatically after that):

Google Calendar

  1. Go to calendar.google.com
  2. In the left sidebar, click the + next to "Other calendars"
  3. Choose From URL
  4. Paste the feed URL above and click Add calendar

Apple Calendar (Mac)

  1. File → New Calendar Subscription…
  2. Paste the feed URL and click Subscribe
  3. Set Auto-refresh to "Every day"

Outlook

  1. Add calendar → Subscribe from web
  2. Paste the feed URL and save

Once subscribed, new and updated events appear automatically—no further prompts or manual imports.
